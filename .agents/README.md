# Agent adapters

This directory is **not** required to run the MemoLens desktop app.

Codex and DeepSeek Harness share read-only media/project tools and a project-bound Browser editor. Data reads stay local and read-only. Path-free Library setup queues an intent for native approval; explicit editor handoff starts a bounded loopback UI. Canonical Save requires a separately approved project/action capability and exact revision reread. Neither surface grants generic filesystem, export or publication authority.
