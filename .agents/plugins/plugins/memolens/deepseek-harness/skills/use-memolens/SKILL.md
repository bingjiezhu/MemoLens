# Use MemoLens from DeepSeek Harness

MemoLens is exposed through server-qualified tools named `mcp__memolens__<tool>`. Use those tools instead of reading the database or calling the backend directly.

If no local Library has been confirmed, call `mcp__memolens__memolens_library_bootstrap_start` with one stable `request_idempotency_key`, then poll `mcp__memolens__memolens_library_bootstrap_status` only with its opaque request ID. Never provide or invent a path, DB locator, project seed, token, proof, or native ticket. `queued_open_memolens` means tell the user to open MemoLens themselves; it is not proof that a packaged app woke or a dialog appeared. Electron's native chooser owns directory authority. `native_cancelled` and `expired` end that request. `library_authority_staged` is recoverable desktop projection state; keep polling the same request. `library_authority_committed` means the exact Core Library, database, project, unverified Blueprint, and immutable receipt-bound scan job exist. It does not prove scan start/completion, semantic confirmation, editor readiness, or Timeline editing. After committed, call `mcp__memolens__memolens_status` and read only `database.library_scan`. Wait on its path-free, receipt-anchored status rather than a raw checkpoint or any newer/rogue scan row. Never infer or expose the private cursor, fingerprint, path, or checkpoint. `scan_complete` and `no_supported_media` still do not independently establish a grounded Timeline or ready editor.

For a new story, check status or confirmed Creator Memory, navigate the Media Wiki or Inbox, resolve exact evidence, then call `mcp__memolens__memolens_timeline_draft`. To resume work, prefer project and Blueprint readers before drafting. Treat Agent proposals and decision projections as evidence, never as user confirmation.

For an existing canonical project, use `mcp__memolens__memolens_canonical_editor_handoff` with only the exact `project_id`. Never pass or invent Timeline JSON, candidates, source identity, paths, actor, or result state. On success, the DeepSeek Web card shows **Open MemoLens Canonical Editor**. If that card is unavailable, return a clickable Markdown link using the exact `uiHandoff.url`; do not rewrite or guess the URL. Opening requires a user gesture and a new browser tab.

The canonical page provides a ruler, scrub playhead, zoom, verified same-session thumbnails, drag reorder, trim handles, video **Split at playhead**, and **Remove clip from Timeline**. The original controls require `timeline.apply_edit`; Split/Remove require independent `timeline.apply_structural_edit`. Split uses absolute `source_split_ms`, at least 100ms per child, and a 256-clip cap. Remove refuses the last clip and leaves original media unchanged. Both stage one top-level `structural_edit` as noncanonical; Discard writes nothing. Request `timeline.preview_media` independently for bounded verified source-preview transport; supported MP4/H.264 current clips can then use Play/Pause/seek through a short-lived project/head/clip-bound proxy. Raw MP4 transport may contain audio, while the page disables audio playback and keeps output muted. Audio-stream presence, content, and mix are not attested; preview does not prove render, export, or final fidelity, and no action implies another. The page keeps current head N separate from read-only historical K. Ordinary, structural, and restore pending states are mutually exclusive. Explicit Save uses the plugin process's server-held project capability and may report N+1 only after exact CAS and canonical reread. The Browser never receives proof secret, capability, nonce, desktop/main token, historical fixed-source identities or bindings, media path, actor/origin, or generic write authority. Save is not semantic confirmation, render, export, or publish authority. On refreshable conflict, review the reloaded current head; for idempotency or unknown post-commit state, retry only the retained exact identity. Never auto-rebase.

Use `mcp__memolens__memolens_editor_handoff` only for the **MemoLens Unsaved Draft Lab** after obtaining an exact Timeline 1.0 value. Its card is **Open MemoLens Unsaved Draft Lab**. Its wider split/delete, ripple trim, move, replace, fit, volume, canvas, drag reorder, undo, and redo are **Not saved / process-scoped** and cannot enter canonical state. Expiry or MCP process exit can discard that draft.
