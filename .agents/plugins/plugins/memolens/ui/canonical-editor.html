How changes and source previews are verified

Original media remains unchanged. Canonical timing is exact while media and authority identity are redacted. Selection, zoom, playhead, Play, Pause, and seek are transient view state. Clip geometry changes only from the server-returned pending preview. A playable video is raw verified source transport that may contain audio; this page disables audio playback and keeps output muted. It does not attest audio-stream presence, content, mix, subtitles, transitions, render, or export, and this page never receives a file path or credential.
