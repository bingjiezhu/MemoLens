How changes and source previews are verified

Original media remains unchanged. Canonical timing is exact while media and authority identity are redacted. Selection, zoom, playhead, Play, Pause, and seek are transient view state. Clip geometry changes only from the server-returned pending preview. Raw MP4 preview transport may contain audio. This page disables audio playback and keeps output muted. Audio-stream presence, content, and mix are not attested; this is not final-fidelity proof. It does not attest audio-stream presence, content, mix, subtitles, transitions, render, or export, and this page never receives a file path or credential.
