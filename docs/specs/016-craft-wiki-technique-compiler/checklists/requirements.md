# Specification Quality Checklist: Craft Wiki & Technique Compiler

**Purpose**：验证 ML-016 是否把“专业能力普惠”转成可测、可解释、可降级的产品规范。

**Created**：2026-08-22
**Feature**：[spec.md](../spec.md)

## Content Quality

- [x] 以用户创作结果与学习体验为中心，而非效果数量或模型名称。
- [x] 明确 Card、Skill、Compiler 与 Timeline operation 的边界。
- [x] 所有 requirement 与 success criteria 可测试。
- [x] 没有 `[NEEDS CLARIFICATION]` 或实施授权。

## Product Alignment

- [x] 人负责思想与取舍，AI 负责繁琐实现并提供建议。
- [x] 支持一键 first cut 与逐步共创。
- [x] 专业性优先来自基础剪辑、声音、字幕和色彩，而非炫技。
- [x] 技巧按本次文稿和素材动态编译，不固定套模板。
- [x] 项目选择不会未经确认写成长期偏好。
- [x] 用户可以理解选择，但不必通过教程才能创作。

## Evidence, Safety and Rights

- [x] Core Craft claim 与参考 observation 都有来源/coverage。
- [x] 未观看内容不会被声称已分析。
- [x] 不默认复制、缓存或复刻无许可作品与资产。
- [x] Agent 只能提交已校验 typed operations。
- [x] 不可用 capability 会降级，不伪装成功。
- [x] 历史项目固定 Card/Skill/compiler revision。

## Experiment Quality

- [x] 与手工、固定模板和自由 LLM 指令公平比较。
- [x] 同时衡量普通用户、专业盲评、耗时、返工和错误。
- [x] 有晋级门槛、kill criteria 和 rollback。
- [x] 没把 Card 数量、术语识别或“电影级”文案当作创新证明。

## Pre-Planning Gate

- [ ] 维护者批准 ML-016 进入计划阶段。
- [ ] 冻结首批 P0 Card taxonomy 与来源审核标准。
- [ ] ADR 固定 Card/Skill/typed operation contract。
- [ ] 建立口播、Vlog、图文故事的同素材 baseline fixtures。
- [ ] 完成参考资产版权、缓存与引用 threat model。
- [ ] ML-015 capability profile 与 operation history contract 已可用。

这些门槛未完成前，只能做研究和离线实验，不得开放自动 render Skill。
