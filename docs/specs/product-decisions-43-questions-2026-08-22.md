5. 新信息若要改变 `DECIDED` 项，必须新增带日期的 superseding decision，不能静默改写本记录。

状态含义：

- `确认`：用户明确接受或主动提出。

## 2. 一句话北极星

> MemoLens 面向拥有大量本地照片和视频的个人自媒体创作者：人负责表达、立场、创意取舍与最终发布，AI 负责调研、建议和繁琐执行；用户只需把素材放进一个 Library 文件夹，并通过任意支持的 Agent 讨论创作，系统就能理解和持续管理私人素材，从意图、文稿或参考样片形成可解释、可编辑、可回退的专业初剪，并在导出时完整记录素材使用情况。

这个产品不是“自动生成一条视频”的单点工具，而是把专业创作团队的工作流压缩成一个灵活的人机协作闭环：

```text
Library 素材进入
  → 可恢复索引与 Agent 可导航素材 Wiki
  → 意图 / 文稿 / 参考 / 历史作品对齐
  → 热点与选题建议（按需）
  → 创作蓝图
  → 素材搜索与逐段画面匹配
  → 可解释技巧建议与专业处理
  → 快速完整初剪
  → 对话 + 可视化工作台精修
  → 导出成片、脚本、字幕、封面与使用清单
  → 使用事实回到素材库
```

| “所有语义理解必须本地完成” | 本地做确定性媒体处理；语义理解由 Codex、Claude 等外部 Agent 的大模型完成，有界提交并记录 payload。 |
| “Codex 是唯一对话表面” | 任何可调用 CLI/标准工具的 Agent 都可接入；Codex 与 Claude 是首批目标，不是领域模型的一部分。 |
| “只有 App 能进行所有写入” | App 仍掌管权限和高影响确认，但 Agent 可以通过受限 CLI 请求 Core 执行版本化写操作；Agent 不得直接写 SQLite 或原文件。 |
| “选题、脚本、成片必须依次阻塞确认” | 默认允许直接生成完整 first cut；用户可按需在任一节点展开、回退和精修。 |
| “已发布才算用过” | 成功导出即记录素材及精确时间段使用；发布状态另算。 |
| “建立完整图数据库才叫高级记忆” | Wiki 是逻辑知识与导航层。首阶段可建立在 SQLite 类型化关系与可重建 projection 上；只有 benchmark 证明收益才引入独立图存储。 |
| “Wiki 等于把素材描述切块后做向量 top-k” | Wiki 采用分层页面、显式关系、证据回链、渐进展开、定向复核和检索轨迹；向量只是一种候选信号。 |

## 5. 不可退回的产品原则

1. **人负责意义，AI 负责执行并提出建议。** AI 不能替用户决定立场或最终发布。
2. **一个 Library 即可开始。** 不以云同步、多来源连接或复杂教程作为冷启动前提。
3. **原件默认永不移动、删除、覆盖或上传。** 衍生索引、预览、素材包与记录可重建、可审计。
4. **视频证据精确到时间段。** 整文件摘要不能替代可直接进入 Timeline 的片段证据。
5. **对话不是项目真源。** Creative Blueprint、Timeline 与 operation history 才能被重放和回撤。
6. **先完整初剪，再任意深挖。** 一键与深度共创是一条连续工作流，不是两个割裂产品。
7. **专业知识降低门槛，不隐藏知识。** 先说效果，再解释技术；实现繁琐步骤由 AI 承担。
8. **Agent 无关，Core 唯一。** CLI、MCP、Codex、Claude 和 UI 使用同一命令语义与状态机。
9. **使用历史是创作资产。** 导出产生具体片段使用账本；已用不等于不可再用，剩余时段继续可发现。
10. **高级搜索必须可验证。** Wiki 页、模型判断、推荐和成片选择都能回到原始 asset、时间范围与分析 revision。
